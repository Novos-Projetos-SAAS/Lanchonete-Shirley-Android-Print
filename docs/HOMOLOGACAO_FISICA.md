# Homologação física pendente

O código foi preparado sem impressora, telefone, Android SDK, Gradle ou ADB disponíveis. Portanto, nenhum APK foi compilado/instalado e nenhuma compatibilidade física é alegada.

Antes de produção, seguir integralmente `../../Lanchonete-Shirley-Backend/docs/44_TESTES_LIMITACOES_E_HOMOLOGACAO_FISICA.md`. Registrar modelo/firmware da impressora, Android/fabricante, code page correta, suporte ao corte, resultados 58/80 mm, falhas de rede/Bluetooth, reinício e carga prolongada.

Também validar: perda de ACK após papel enviado, retomada após processo morto, desvinculação com/sem rede, Bluetooth desligado, permissões negadas, TalkBack, fonte no maior tamanho, tema escuro, orientação paisagem e confirmação do teste local. Nenhum desses itens foi alegado como aprovado na Etapa 10.
